## Checklist manuelle
### 3.1 Réponses IA — OK
Le slug est construit à partir d'une traduction déjà stockée et sanitizée, puis normalisé en ASCII par `sanitize_title( remove_accents( wp_strip_all_tags() ) )` (SlugGenerator::normalize, inchangé). `is_source_copy()` passe la valeur source par `preg_quote()` avant de l'utiliser dans l'expression rationnelle (src/Router/SlugGenerator.php:105).

### 3.2 Contrôle d'accès — OK
- Nouvelle route `POST /omtr/v1/slugs/refresh` (src/Router/SlugRestController.php:55-63), avec `permission_callback` `Capabilities::rest_permission` (`omtr_manage`). Elle est appelée par `apiFetch` avec le nonce REST. Le test `SlugRestControllerSecurityTest` vérifie maintenant toutes les routes de slugs et refuse anonyme et abonné.
- Elle ne fait que poser une option interne : aucun paramètre accepté, aucun travail lourd dans la requête.
- Les slugs saisis à la main restent intouchables : seule une copie exacte de l'URL source (post_name ou titre source, éventuellement suffixé `-N`) est remplacée (tests `test_manual_slug_is_preserved`, `test_slug_extending_the_source_url_is_not_a_copy`).

### 3.3 Clés API — OK
Non concerné.

### 3.4 Abus et coûts — OK
- Le recalcul **n'appelle jamais l'IA** : il lit les traductions existantes (`find_many`).
- Il tourne en arrière-plan (Action Scheduler, `as_enqueue_async_action`), une seule fois à la fois (`as_has_scheduled_action`, test `test_an_already_scheduled_refresh_is_not_duplicated`), jamais pendant la requête d'un visiteur.
- Le bouton répété ne crée pas de doublons.
