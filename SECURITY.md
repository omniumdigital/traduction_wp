# Politique de sécurité

## Signaler une vulnérabilité

Ne publiez pas de ticket public. Écrivez à **hello@omnium-digital.fr** avec :

- la version concernée d'Omnium Translate ;
- la description et les étapes de reproduction ;
- l'impact estimé.

Accusé de réception sous 72 h. Un correctif est publié **sous 7 jours** pour une vulnérabilité critique, puis annoncé dans le `CHANGELOG.md`.

## Versions supportées

Seule la dernière version publiée reçoit des correctifs de sécurité.
